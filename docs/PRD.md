## 1. 产品目标

> **一句话定位**：打造银行内部授信尽调工作台，对接企查查数据源，自动化完成企业多维画像、风险扫描和信用评级，将单笔尽调耗时从 2-3 天压缩至 30 分钟内。

| # | 目标 | 衡量指标 |
|---|---|---|
| G1 | **尽调效率提升** | 单笔尽调全流程 ≤ 30 分钟（含报告生成） |
| G2 | **风险识别准确率** | 借助企查查多维数据，高风险企业漏报率 ≤ 5% |
| G3 | **授信决策标准化** | 100% 尽调输出标准化 A/B/C/D 评级和结构化报告 |

---

## 2. 用户角色与权限

| 角色 | 描述 | 权限范围 |
|---|---|---|
| **信贷审批员**（核心用户） | 对公贷款收单人员，日常执行尽调 | 创建尽调任务、查看所有模块数据、生成/导出报告 |
| **部门主管** | 审批员上级，负责复核和决策 | 查看所有尽调任务、修改评级、批复意见、导出报告 |
| **系统管理员** | IT/运营人员 | 用户管理、企查查 API 密钥管理、系统配置 |
| **只读观察员**（可选） | 风控/合规部门 | 仅查看报告和评级结果，不可编辑 |

## 3. 核心功能模块

### 3.1 企业信息检索与核验

| 功能点 | 说明 | 优先级 |
|---|---|---|
| 企业名称/信用代码模糊搜索 | 支持输入企业名称、简称、信用代码进行模糊匹配，返回候选列表 | P0 |
| 企业身份核验 | 核验企业全称 + 统一社会信用代码二要素一致性 | P0 |
| 企业基本信息展示 | 名称、统一社会信用代码、注册地、法定代表人、成立日期、注册资本、经营状态、经营范围 | P0 |
| 企业简称/曾用名展示 | 辅助确认目标企业身份 | P1 |

### 3.2 工商数据展示

| 功能点 | 说明 | 优先级 |
|---|---|---|
| 股东信息 | 直接股东列表（名称、持股比例、认缴/实缴、出资时间） | P0 |
| 高管/董监高信息 | 法定代表人、董事、监事、高级管理人员列表及职务 | P0 |

| 历史股东/高管变更 | 历史股权变更轨迹、高管变动记录 | P1 |

### 3.4 财务数据分析（企查查工商财报）

> **说明**：本模块数据来源为企查查 API，展示企业工商年报中的财务数据。
> 客户自行上传的财报（审计报告/税务财报）由 **3.5 财报数据**模块处理。

| 功能点 | 说明 | 优先级 |
|---|---|---|
| 工商财报展示 | 资产负债合计、所有者权益合计、营业收入、利润总额、纳税总额等历史数据 | P0 |
| 关键财务指标 | 营收、净利润、资产负债率、流动比率、ROE 等核心指标（基于工商财报计算） | P0 |
| 财务趋势可视化 | 近 3-5 年关键指标折线/柱状图 | P1 |

### 3.5 财报数据（客户上传：审计财报/税务财报）

> **说明**：本模块处理客户自行上传的财报文件（审计报告、年度/季度财务报表）。
> 企查查工商财报数据由 **3.4 财务数据分析**模块处理。

| 功能点 | 说明 | 优先级 |
|---|---|---|
| 财报文件上传 | 支持上传企业审计报告、年度/季度财务报表（PDF/Excel） | P0 |
| 财报数据解析 | 自动提取上传财报中的关键数据（资产总额、负债总额、营收、净利润等） | P0 |
| 多期财报对比 | 同一企业多期财报核心指标同比/环比对比 | P0 |
| 财报一致性校验 | 将上传财报数据与企查查工商财报数据交叉比对，标注差异 | P1 |
| 财报异常预警 | 收入与纳税不匹配、利润大幅波动、资产负债率异常等预警提示 | P1 |

### 3.6 银行流水

> **说明**：银行流水由本行内部系统提供（企业在本行开立的结算账户），审批员在创建尽调任务时系统自动拉取，无需客户上传。

| 功能点 | 说明 | 优先级 |
|---|---|---|
| 流水文件上传 | 支持上传企业银行流水单（Excel/PDF/图片格式） | P0 |
| 流水数据解析 | 自动解析银行流水，提取交易日期、交易对手、收付款金额、余额等信息 | P0 |
| 流水统计分析 | 统计期间流入/流出总额、日均余额、最大单笔、交易频次 | P0 |
| 流水趋势可视化 | 月度资金流入/流出柱状图、余额走势折线图 | P0 |
| 异常交易识别 | 大额收支、同名账户频繁转账、非经营性往来等异常标注 | P1 |
| 多账户汇总 | 支持同一企业多个银行账户流水汇总分析 | P1 |

### 3.10 自动信用评级（A/B/C/D）

| 功能点 | 说明 | 优先级 |
|---|---|---|
| 多维评分模型 | 基于工商、司法、财务、股权等多维度数据计算综合得分 | P0 |
| A/B/C/D 等级输出 | 自动给出信用等级和建议授信额度区间 | P0 |
| 评分明细展示 | 展示各维度得分及权重，支持审批人员理解评级依据 | P0 |
| 人工调整评级 | 审批人员可在系统评级基础上手动调整，需填写调整理由 | P0 |
| 评级历史追溯 | 同一企业多次尽调的评级变化趋势 | P1 |

**评分模型（初版草案）**

| 维度 | 权重 | 评分依据 |
|---|---|---|
| 司法风险 | 20% | 诉讼数量、失信记录、限高令、行政处罚 |
| 财务健康 | 20% | 营收趋势、盈利能力、资产负债率、现金流 |
| 征信状况 | 20% | 企业征信/法人征信：逾期、欠息、多头借贷、授信使用率 |
| 经营稳定性 | 15% | 成立年限、工商变更频率、经营异常记录 |
| 股权结构 | 15% | 股权穿透清晰度、实控人稳定性、关联交易 |
| 合规状况 | 10% | 行政许可、环保处罚、税务异常 |

## 8. 非功能性需求

| 类别 | 要求 |
|---|---|
| **性能** | 单笔尽调数据采集完成 ≤ 60 秒；页面加载 ≤ 3 秒 |
| **可用性** | 支持主流浏览器（Chrome/Edge/Firefox 最新 2 版） |
| **安全** | 登录态 Token 认证；企查查 API 密钥服务端加密存储；操作日志记录 |
| **数据准确性** | 企查查数据 T+0 实时更新；显示数据采集时间戳 |
| **可维护性** | 前后端分离；后端模块化（每个数据源独立 Service）；评分模型参数可配置 |
